# CodSoft Data Analytics Internship - Task 4: Customer Data Analysis & Segmentation

## Overview
Customer segmentation pipeline using RFM (Recency, Frequency, Monetary) metrics and K-Means clustering.

## Customer Segments & Strategies
- **High-Value VIPs**: Targeted with exclusive loyalty tiers and early access releases.
- **Loyal Core Customers**: Upsold via minimum spend basket discounts.
- **At-Risk / Low Spenders**: Re-engaged with personalized discount coupons.

## Tools Used
- Python 3
- Pandas, Scikit-learn (K-Means, StandardScaler), Seaborn, Matplotlib# CODSOFT_TASK4
